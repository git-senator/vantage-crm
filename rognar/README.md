# Рогнар — разведка лидов в публичных Telegram-чатах

Слушает чаты, где аккаунт уже состоит, находит людей, которые ищут недвижимость,
и присылает владельцу сигнал в личку. Дальше владелец решает, писать человеку
или нет — сам Рогнар **никому не пишет и никуда не вступает**.

```
публичные чаты
   ↓ (аккаунт-слушатель молча читает)
предфильтр по словам  ·  RU / EN / PT
   ↓
модель: живой лид или трёп?
   ↓
@Rognar_brazil_bot  →  владельцу в ЛС
```

Почему так, а не «бот сам всех обрабатывает»: массовые вступления и авто-ответы
незнакомым людям — прямой путь к бану аккаунта и жалобам на спам. Чтение —
безопасно, решение о контакте остаётся за человеком.

## Где он работает

**В бою — на VPS, в `/opt/rognar`.** Отдельный compose-проект со своей сетью,
без открытых портов и общих томов: наружу он только читает Telegram и спрашивает
модель, дотянуться до CRM или n8n не может. Живёт вне `/opt/vantage`, поэтому
обычный `git pull` для обновления CRM его не касается.

```bash
cd /opt/rognar
docker compose logs -f      # что происходит сейчас
docker compose restart      # перезапустить
docker compose up -d --build   # после обновления кода
```

Новые чаты подхватываются сами: вступил с телефона — через несколько минут
Рогнар уже слушает, перезапускать ничего не нужно.

> ⚠️ Один аккаунт — один запущенный Рогнар. Если поднять второй (например,
> локально), клиенты подерутся за сессию и рабочий упадёт. Локальная копия
> сессии лежит как `rognar.session.local-backup` именно поэтому: чтобы её
> нельзя было запустить случайно.

## Настройки

Всё в файле `.env` рядом с compose (в git не попадает):

| Переменная | Что это |
|---|---|
| `ROGNAR_BOT_TOKEN` | бот-почтальон от @BotFather |
| `ROGNAR_OWNER_CHAT_ID` | `chat_id` владельца — берётся после `/start` боту |
| `ROGNAR_API_ID` / `ROGNAR_API_HASH` | с https://my.telegram.org → API development tools |
| `ROGNAR_WATCH_JOINED` | `false` — слушать только `watchlist.txt` (по умолчанию слушает все группы аккаунта) |
| `AI_API_KEY` / `AI_API_BASE` / `AI_MODEL` | модель-судья (Groq) |

`ROGNAR_PHONE` нужен только при первом входе.

## Кого слушать

По умолчанию — **все групповые чаты аккаунта**. Личная переписка и
каналы-вещания не берутся никогда, а рабочие и семейные группы вписываются в
`ignore.txt`.

`watchlist.txt` добавляет чаты сверх этого — на случай, если автоподхват выключен.

## Инструменты разведки

```bash
python scout.py candidates.txt   # замерить чаты из списка
python find.py br es             # найти новые (ru, kz, ca, us, br, es)
python diag.py                   # проверить, живы ли текущие
```

`scout.py` читает историю публичного чата и считает **сообщений в час** —
вступать для этого не нужно. Это единственная честная метрика: счётчик «онлайн»
на превью-странице показывает, сколько человек держат приложение открытым, и
однажды выдал за перспективный чат, молчавший 218 дней. Заодно скрипт находит у
канала группу обсуждений — в самом канале пишут только админы, читатели с
вопросами сидят рядом.

`find.py` спрашивает поиск Telegram на языке аудитории («investimento
imobiliário», а не «real estate») и сразу прогоняет находки через замер.

> Все три работают с тем же файлом сессии, что и слушатель, поэтому на сервере
> его нужно остановить на время (`docker compose stop`). Замок не даст запустить
> два клиента разом и объяснит, кто держит сессию.

> ⚠️ На сервере код **вшит в образ**. Скопировать изменённый `.py` в
> `/opt/rognar` мало — `docker compose run` возьмёт старую версию из образа и
> отработает молча, по-прежнему. После любой правки:
> `docker compose build`, и только потом запускать.

## Настройка чувствительности

- `config.py` → `TRIGGERS` — слова-зацепки по языкам. Глагол требует объекта
  рядом: «купить» без жилья ловит гречку и зря будит модель.
- `config.py` → `NOISE_RE` — что считать объявлением и отбрасывать до модели.
- `rognar.py` → `SCORE_FLOOR` (55) — ниже этой оценки сигнал не шлём.
- `rognar.py` → `DEDUP_WINDOW` — как долго не дёргать повторно одного автора.

Отказ модели **не** считается вердиктом «не лид»: сообщение уходит владельцу с
пометкой «не проверено AI». Пропущенный покупатель дороже лишнего уведомления.

## Первый запуск на новой машине

```bash
pip install -r requirements.txt
python login.py     # Telegram пришлёт код, ввести вручную — один раз
python rognar.py
```

`start.ps1` — то же самое под Windows, с автоперезапуском после сбоя.

## Границы

- Аккаунт-слушатель видит все чаты, где состоит: под него лучше отдельный номер,
  а не личный с админкой каналов.
- Telegram ограничивает число чатов на аккаунт (~500, с Premium ~1000).
- Массовые вступления — главный триггер антиспама, поэтому вступаем вручную и
  понемногу.
