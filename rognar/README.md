# Рогнар — разведка лидов в публичных Telegram-чатах

Слушает чаты, где аккаунт уже состоит, находит людей, которые ищут недвижимость,
и присылает владельцу сигнал в личку. Дальше владелец решает, писать человеку
или нет — сам Рогнар **никому не пишет и никуда не вступает**.

```
публичные чаты
   ↓ (аккаунт-слушатель молча читает)
предфильтр по словам  ·  RU / EN / PT
   ↓
модель: живой лид или трёп?
   ↓
@Rognar_brazil_bot  →  владельцу в ЛС
```

Почему так, а не «бот сам всех обрабатывает»: массовые вступления и авто-ответы
незнакомым людям — прямой путь к бану аккаунта и жалобам на спам. Чтение —
безопасно, решение о контакте остаётся за человеком.

## Установка

```bash
pip install -r rognar/requirements.txt
```

Секреты — в `.env.rognar` в корне проекта (в git не попадает):

| Переменная | Что это |
|---|---|
| `ROGNAR_BOT_TOKEN` | бот-почтальон от @BotFather |
| `ROGNAR_OWNER_CHAT_ID` | `chat_id` владельца — берётся после `/start` боту |
| `ROGNAR_API_ID` / `ROGNAR_API_HASH` | с https://my.telegram.org → API development tools |
| `ROGNAR_PHONE` | номер аккаунта-слушателя (можно оставить пустым, спросит при входе) |

Ключ модели переиспользуется из основного `.env` проекта: `AI_API_KEY`,
`AI_API_BASE`, `AI_MODEL`.

## Запуск

```bash
# 1. Разовый вход слушателя — Telegram пришлёт код, ввести вручную
python rognar/login.py

# 2. Слушать (Ctrl+C — стоп)
python rognar/rognar.py
```

## Кого слушать

`watchlist.txt` — по хэндлу в строке. В **чаты** аккаунт должен вступить
руками; **каналы** читаются и без подписки.

Перед тем как вступать, стоит проверить, живое ли место:

```bash
python rognar/tg_probe.py rognar/watchlist.txt out.csv
```

Скрипт читает публичную превью-страницу `t.me/<handle>` и показывает: живой ли
хэндл, чат это или канал, сколько людей и **какой процент онлайн**. Последнее —
самая честная метрика: 930 участников при 3 онлайн это кладбище, а 493 при 76
онлайн — место, где реально разговаривают.

## Настройка чувствительности

- `config.py` → `TRIGGERS` — слова-зацепки по языкам; `NOISE_RE` — что считать
  рекламой и отбрасывать до модели.
- `rognar.py` → `SCORE_FLOOR` (по умолчанию 55) — ниже этой оценки сигнал не шлём.
- `rognar.py` → `DEDUP_WINDOW` — как долго не дёргать повторно одного автора.

## Границы

- Аккаунт-слушатель видит все чаты, где состоит, — поэтому под него лучше
  завести **отдельный номер**, а не использовать личный с админкой каналов.
- Telegram ограничивает число чатов на аккаунт (~500, с Premium ~1000).
- Массовые вступления — главный триггер антиспама, поэтому вступаем вручную и
  понемногу.
